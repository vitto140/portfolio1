## Frameworks and tools

- HTML: the structure of the home, ways and booking pages.
- CSS: the night-sky theme, the stars and the large moon.
- JavaScript: the button that turns the background sound on and off.
- PHP: A form that sames user info.
## Features

- A home page with a ghost logo, a starry sky and a large moon
- Navigation to the home, ways and booking pages, with the Book link styled as a button
- A sound toggle, muted by default
- Form connected to a database
- Javascript animations

## What I learned

A fun theme only works if every detail follows it, from the fonts to the copy. I also learned to keep sound muted until the visitor chooses to turn it on.
